# v0 전용 기술층

**이 문서는 v0 에서만 쓴다.** ChatGPT Sites 는 코드를 보여주지 않으므로 여기 적힌 지시가 통하지 않는다. Sites 로 만들 때는 `common/` 만 쓰고 이 파일은 열지 않는다.

공통층(`common/00-core.md`)이 무엇을 만들지 정한다면, 이 문서는 그것을 v0 가 어떻게 구현할지 정한다. 순서가 뒤바뀌면 안 된다 — 구조를 먼저 확정하고 구현을 나중에 정한다.

## 스택

v0 의 기본 스택을 그대로 쓴다. Next.js App Router, Tailwind CSS, shadcn/ui. 별도 UI 라이브러리를 추가하지 않는다.

가게 소개 한 장에 상태 관리 라이브러리, 폼 라이브러리, 애니메이션 라이브러리를 넣지 않는다. 페이지 하나에 그만한 의존성이 붙으면 나중에 수강생이 손댈 수 없다.

## 색과 타이포

색은 업종에 맞게 정하되 다음을 지킨다.

- 본문 글자와 배경의 명도 대비를 충분히 둔다. 밝은 야외에서 휴대폰으로 읽는 상황이 기준이다.
- 색은 세 갈래로 제한한다. 배경, 본문, 강조 하나. 강조색은 버튼과 가격에만 쓴다.
- 회색 글자를 본문에 쓰지 않는다. 보조 설명에만 쓴다.

글자 크기는 본문 16 이상으로 잡는다. 나이 든 손님이 주 사용자다. 가격은 본문보다 크게 잡아 스캔할 때 눈에 걸리게 한다.

## 레이아웃

- 모바일 우선으로 작성하고 넓은 화면은 최대 폭을 두어 가운데 정렬한다.
- 가로 스크롤을 만들지 않는다. 표는 좁은 화면에서 세로로 쌓이게 한다.
- 대표항목은 카드 세 개로 나열한다. 좁은 화면에서 한 열, 넓은 화면에서 세 열.
- 영업시간은 표로 만들되 좁은 화면에서 요일과 시간이 두 줄로 접히게 한다.

## 화면 효과

절제한다. 가게 소개 한 장에 화려한 효과는 손님이 정보를 찾는 것을 방해한다.

- 스크롤해서 각 구획이 화면에 들어올 때 짧게 나타나는 효과를 준다. 지속 시간은 짧게 잡고 이동 거리는 작게 둔다.
- 버튼에는 눌리는 느낌만 준다. 크기가 커지거나 회전하지 않는다.
- 자동 재생되는 배너나 슬라이드를 넣지 않는다. 손님이 읽는 중에 화면이 바뀌면 안 된다.
- 화면 효과를 끈 사용자 설정을 존중한다. 그 설정에서는 효과 없이 바로 보이게 한다.

## 접근성

- 전화번호는 전화 걸기 링크로, 주소는 지도 링크로 만든다.
- 이미지에는 무엇이 찍혔는지 설명을 붙인다.
- 버튼은 손가락으로 누를 수 있는 크기로 만든다.
- 제목 단계를 건너뛰지 않는다.

## 배포

v0 의 배포 버튼으로 올린다. 무료 계정에서도 배포된다.

**다만 무료 배포 경로는 연습·실습용이다.** 가게 홍보로 상시 운영하는 것은 무료 플랜 약관 밖이다. 근거와 대안은 레포 최상단 `README.md` 의 배포 경로 제약 절에 있다.
