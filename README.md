# 바이브코딩 지침 하네스

말로 홈페이지를 만드는 수업에서, 누가 하든 같은 구조와 같은 품질 하한선이 나오게 하는 지침 정본이다.

## 수강생은 이것만 하면 된다

1. [`common/10-long-prompt.md`](common/10-long-prompt.md) 를 연다.
2. 대괄호 `[ ]` 자리를 내 가게 정보로 바꾼다.
3. 전체를 복사해 v0 또는 ChatGPT Sites 대화창에 **한 번에** 붙여넣는다.

만들고 나면 [`checklists/common-5.md`](checklists/common-5.md) 로 채점한다. 미달 항목이 있으면 그 항목에 붙은 재생성 프롬프트를 그대로 붙여넣는다.

## 층위 — 도구가 바뀌어도 안 삭는 것과 삭는 것

**도구 불변부** (`common/`, `checklists/`) 는 어떤 빌더에서도 참이다. 무엇이 화면에 있어야 하는지를 다루지, 어떻게 만드는지를 다루지 않는다.

**도구 의존부** (`v0/`, `docs/`, 루트 `SKILL.md`·`v0.json`) 는 특정 도구의 화면과 절차에 묶인다. 각 파일 상단에 `실측일 / 확인 계정 / 확인 화면` 헤더가 있고, 90일이 지나면 검사기가 경고하고 180일이 지나면 실패한다.

`v0` 는 코드를 보여주고 ChatGPT Sites 는 보여주지 않는다. 그래서 코드 규칙·디자인 토큰·애니메이션 지시는 `v0/` 안에만 있다. `common/` 에 그런 지시가 한 줄이라도 섞이면 Sites 경로가 깨진다.

## 배포 경로 제약 — 만들기 전에 읽는다

만드는 것과 계속 띄워두는 것은 다른 문제다. **가게 홍보에 쓸 거라면 이 절을 먼저 읽는다.**

| | v0 (Vercel) | ChatGPT Sites |
|---|---|---|
| 무료 플랜으로 상시 운영 | ❌ Vercel Hobby 는 비상업·개인 사용 한정 | — |
| 상업적 사용 | Vercel Pro 이상 필요 | ✅ 약관이 외부 결제사 연결까지 명시 허용 |
| 근거 | [Vercel Hobby 플랜](https://vercel.com/docs/plans/hobby), [fair use 가이드라인](https://vercel.com/docs/limits/fair-use-guidelines) | [ChatGPT Sites 약관 §2.6](https://openai.com/policies/chatgpt-sites-terms/) |

Vercel 의 fair use 정의는 상품·서비스 광고, 결제 처리, 제휴 링크, 후원 요청까지 상업적 사용으로 본다. **연습과 실습은 무료 플랜으로 충분하고, 가게 홈페이지를 상시 운영하려면 유료 경로가 필요하다.**

요금과 사용 한도는 수시로 바뀐다. 이 문서는 숫자를 적지 않고 공식 문서로 보낸다 — [v0 요금제](https://v0.app/pricing) · [ChatGPT 요금제](https://openai.com/chatgpt/pricing/).

## 기여

이 레포는 강의 교안의 정본이다. 외부 기여는 **issue 로 받고, PR 병합 여부는 강사가 판단한다.** 지침 문구는 강의 진행과 직결되므로 임의 변경을 병합하지 않는다.

고칠 것을 발견했다면 issue 에 다음을 적는다.

- 어느 파일 어느 문장인가
- 무엇이 틀렸는가 (오타 / 사실 오류 / 도구 화면과 불일치)
- 언제 어느 화면에서 확인했는가

변경을 제안한다면 `node scripts/check-harness.mjs` 가 통과하는 상태로 올린다. CI 가 같은 검사를 돌린다.

### 검사기를 고칠 때

`scripts/check-harness.mjs` 의 **술어 목록 변경은 체크리스트 항목 변경과 같은 커밋에 넣지 않는다.**

항목이 검사에 걸렸을 때 항목을 고치는 대신 목록을 넓히면, 게이트가 산출물에 맞춰 움직인다. 그렇게 한 번 열리면 다음번에 "좋다 / 낫다 / 편하다" 같은 정도를 묻는 말이 같은 절차로 들어오고, 그 순간 이 검사는 아무것도 거르지 못한다.

목록을 넓혀야 한다면 **왜 기존 술어로 표현할 수 없는지**를 커밋 본문에 적는다. 표현할 수 있으면 항목을 고친다.
